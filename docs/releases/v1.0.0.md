# v1.0.0 — Quán Ăn Chợ Nổi

## Điểm mới

- Lặn/hái, quán và vòng `gather → quan → shop`, `D1–D5` (lặp ở `D6–D10`) và nâng cấp `oxygen`/`hp`.
- Cá bơi/sinh theo seed, Cá Sấu Năm Chèo và mất giỏ LIFO.
- Kho cá thể có `id`/`fresh`; hao tươi (`-0.5/s` ở giỏ, `-0.25/s` ở kho quán), giữ lại khi ươn và chốt `base_price` theo độ tươi.
- Contract v1.3 khai `bench_cmd` (`python3 -m chonoi.bench`) và `soak_cmd` (`python3 -m chonoi.soak`); giao diện Canvas có menu/pause/HUD, 3 cảnh báo rõ ràng (thủy quái gần, oxy sắp hết, khách sắp giận) và chế độ tương phản cao (`H` hoặc `?hc=1`).

## Chạy ZIP trên macOS/Linux

Python 3.10+, trình duyệt Canvas. Giải nén, cd vào thư mục có game.contract.json:

```bash
python3 -m chonoi.live --mode day --days 1 --port 0
```

Mở localhost in ra. WASD/mũi tên di chuyển; E tương tác; Space bắt cá; Esc/P pause; R chơi lại. Shop mua bằng nút, Enter đóng. Test: `PYTHONPATH=tests:. python3 -m unittest discover -s tests -v`.
