# v1.0.0 — Quán Ăn Chợ Nổi (bản nháp, chưa phát hành)

## Điểm mới

- Lặn/hái, quán và vòng gather → quan → shop, D1–D5 và nâng cấp oxy/Máu.
- Cá bơi/sinh theo seed, Cá Sấu và mất giỏ LIFO.
- Kho cá thể có ID/độ tươi; hao tươi và giá theo nguyên liệu.
- Contract v1.3 khai bench/soak; Canvas có menu/pause/HUD. Cảnh báo/tương phản cao và các phép đo chỉ ghi là đã kiểm khi có artifact thật.

## Chạy ZIP trên macOS/Linux

Python 3.10+, trình duyệt Canvas. Giải nén, cd vào thư mục có game.contract.json:

```bash
python3 -m chonoi.live --mode day --days 1 --port 0
```

Mở localhost in ra. WASD/mũi tên di chuyển; E tương tác; Space bắt cá; Esc/P pause; R chơi lại. Shop mua bằng nút, Enter đóng. Test: `PYTHONPATH=tests:. python3 -m unittest discover -s tests -v`.

## Artifact khi phát hành
